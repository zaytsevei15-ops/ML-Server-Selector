Use original geometric shield/orbit artwork, not game logos or hero artwork. No official affiliation, invented latency or connection status.

## Brand & Colors

One token set, consumed per platform:

- **Web & desktop**: CSS variables in `packages/web/src/web/styles.css` (desktop loads the web UI).
- **Mobile**: `Colors.light` / `Colors.dark` in `packages/mobile/constants/theme.ts`, read via `useColors()`; `userInterfaceStyle: "automatic"` follows the system light/dark setting.

## Typography

Bundled Rajdhani Bold for Latin display and numeric labels; Manrope Regular/Semibold/Bold for Russian and body. 20px gutters, 8px rhythm, minimum 44px touch targets. Dark theme: #071528 background, #102A47 panels, #315476 borders, #F1D18B gold, #7DD9FF cyan. Light theme keeps blue and warm gold with readable contrasts. Beveled 3–6px corners instead of pill/card-heavy UI. Hero: gold crest over layered orbital diamonds; destination, honest engine status and primary VPN action visible immediately. Decorative geometry is non-interactive and screen-reader-hidden. Compact source row, country roster, separate explanatory notice below the roster. Shared panels/buttons/inputs/tabs carry the game-lobby vocabulary to all screens. Max width 720px in web preview.

## Key User Flows
Revision 1.4: Settings → Administrator / local editor, no remote privileges or authentication. Three editor tabs for geography, custom text, and current VPN Gate node visibility/highlight. Explicit save and visible persistence status; hide/show rather than destructive delete; per-country restore and confirmed all-local reset. Keep technical VPN warnings non-editable; custom hints shown separately. Non-sensitive edits use AsyncStorage on native/sessionStorage in preview, not encrypted. Countries/cities overrides never replace endpoint addresses/certificates. Section numbers 1/2/3/4 without zero padding. No new backend tables or endpoints.
Revision 1.3: expand only Russia to 30 city preferences with local city search and count. Selected-node measurement card shows actual Android ICMP RTT samples/median/loss, time and VPN state at measurement. Manual, three probes, no background polling; unavailable on web/Expo Go, no synthetic ping. ICMP silence is not proof the OpenVPN port is offline. New native package generated by Expo plugin, no new backend route or database.

1. Versioned bilingual consent → country/search/region filter → city → saved destination. Russia is first: Moscow, Saint Petersburg, Kazan, Yekaterinburg, Novosibirsk.
2. Live VPN Gate countries + country-level OpenVPN nodes, metadata-only list, explicit source-reported ping/speed, no invented city or online status. Source refresh and server-side structural profile check. Native Android OpenVPN TurboModule integration: explicit permission, event-only connection state, disconnect, opt-in auto-connect on launch, bounded timeout. Web/Expo Go cannot tunnel. Android build/device verification remains required. No external VPN app links.
3. My server → in-memory ID → format result, explicitly unknown geographical region → official support.
4. Settings → dark/light and RU/EN → encrypted native preferences, including chosen non-sensitive location. No player ID persisted.
5. Advanced Server remains separate information, never part of VPN routing. Remove all game cache checklist from country screens.

## Architecture

- **API**: typed oRPC client (`lib/api.ts` in each package) → the backend in `@template/web`. Query/mutation hooks live in `queries/` (one file per feature); pages/screens call them with `@tanstack/react-query`.
- **State/sync**: TanStack Query with a 60-second freshness window; load only after consent. Explicit errors, manual refresh, no fake successful connections.
- **Auth / payments / uploads**: see `skills/app/references/` when those features are needed.
